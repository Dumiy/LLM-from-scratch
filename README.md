# LLM From Scratch

A guided relearning path back to ML/AI engineering fundamentals — for an engineer who already works with AI/ML, going back to first principles on the way to building an LLM from scratch.

## Purpose

Refresh and rebuild core ML Engineer / Researcher skills: math foundations, classical ML, neural network internals, and modern deep learning, culminating in implementing a language model from the ground up.

## Status
